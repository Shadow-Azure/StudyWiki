# 动态加载

[English](dynamic.en.md) | 中文

> 类型：参考 | 读者：插件作者、AI agent 与维护者。写插件见 [contract.md](contract.md)；发布见 [authoring.md](authoring.md)。

## 行为契约

插件面板（顶栏"插件"）的操作本窗即时生效：安装/导入（联网或本地 tgz → 落盘 → 写清单 → 激活）、启停、重载、移除、回退。清单更新在本窗串行读-改-写，失败释放队列；跨窗无锁，并发写 last-writer-wins，下次启动按最终清单对齐。其他窗口不即时跟随；清单是跨窗准源。

## 重新加载

重新加载先验证后切换：新代码要过装载校验（形状 / apiVersion / inject 形状）才动旧版；激活审计（轮询 fiber 到 ACTIVE，2 秒上限）失败时自动用内存中的旧模块恢复运行，面板行内报错。同一插件的操作串行排队，连点不交错。

## 版本仓

成功激活自动留一代快照（`plugins/.history/<name>/`，内容 hash 去重，每插件保留 10 代）；失败重载回退内存旧模块时不快照坏活目录，不新增从未运行的一代。面板"历史"展开版本列表，"回退"把选中代原子写回活目录——启用行随即热重载，停用行只落盘、下次激活时生效。"（当前）"是磁盘事实而非运行态；坏活目录可能无匹配代，列表可全部不标，内存仍跑旧模块。`meta.json` 只含 hash、createdAt、version、apiVersion，入口名以 package.json 为准；旧 meta 多余字段可读，缺/坏 meta 的代不列。版本仓只增不改、不自动激活；移除先删活目录，历史尽力删；失败留日志、不阻塞。

## 激活失败的去处

安装即激活失败：目录与清单保留，面板行点名原因，下次启动自动重试。停用失败与回退失败：旧状态保持，错误内联显示。装载期失败的行不影响其他任何插件。
