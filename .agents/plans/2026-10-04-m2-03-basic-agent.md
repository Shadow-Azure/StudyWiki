> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 m2-03：cordis 双插件 `agent-core`（`ctx.agent` 服务：回合 loop + read/grep/write/edit 四工具 + 审批门 + JSONL 持久会话 + compaction）与 `app-agent`（右栏 UI，取代 app-chat），配套宿主/Rust 契约扩展（原生 function calling、rg sidecar grep、动态越界授权、会话追加写）。

**Tech Stack:** Tauri 2（std::process sidecar、serde_json）、TypeScript、cordis（vendored）、Vitest/jsdom、cargo test、ripgrep（sidecar）。

```rust
use std::{env, fs, path::PathBuf};

/// 构建期把 @vscode/ripgrep 的平台二进制落位为 Tauri sidecar（npm 当仓库用，
/// 运行零下载；node_modules 缺失时明确指向 pnpm install）。同时导出 TARGET_TRIPLE
/// 供运行期解析 sidecar 文件名。
fn main() {
    let target = env::var("TARGET").expect("TARGET 由 cargo 提供");
    let windows = target.contains("windows");
    let exe = if windows { "rg.exe" } else { "rg" };
    let manifest = PathBuf::from(env::var("CARGO_MANIFEST_DIR").unwrap());
    let src = manifest.join("../node_modules/@vscode/ripgrep/bin").join(exe);
    let out_dir = manifest.join("binaries");
    fs::create_dir_all(&out_dir).expect("创建 binaries 目录");
    let dst = out_dir.join(format!("rg-{target}{}", if windows { ".exe" } else { "" }));
    let stale = fs::metadata(&dst).map(|m| m.len()) .unwrap_or(0)
        != fs::metadata(&src).map(|m| m.len()).unwrap_or(usize::MAX);
    if stale {
        fs::copy(&src, &dst).unwrap_or_else(|e| {
            panic!("落位 rg sidecar 失败：{e}（{} 缺失？先跑 pnpm install）", src.display())
        });
    }
    println!("cargo:rerun-if-changed={}", src.display());
    println!("cargo:rustc-env=TARGET_TRIPLE={target}");
    tauri_build::build()
}
```
