# Agent Note: README 产品化导览与视频入口

Status: implemented

[English](2026-10-30-readme-product-tour.en.md) | 中文

## Problem

原 README 以开发命令和仓库结构为主，首次到访者难以迅速理解产品价值，也看不到真实界面。项目已经具备多格式阅读、Agent 与插件能力，需要与其成熟度相称的入口，同时避免把首页扩成重复架构文档的长页。

## Decision

首页采用“价值一句话 → 真实工作区 → 四类连续体验 → 源码快速开始 → 离线边界”的顺序。参考 GitHub Trending 中 TradingAgents、Impeccable、Superpowers 和 T3 Code 的首屏表达，但不复制其徽章、新闻或冗长安装矩阵。新增约一分钟的横屏中文视频，以当前 `main` 构建的隔离实例截图和 MiMo TTS 旁白介绍产品；README 图片本身也是视频入口。截图使用虚构演示资料，不带入用户插件、模型配置或个人文件。

## Alternatives considered

- 只润色文字：成本低，但无法让访客直观判断桌面产品的形态。
- 放动态 GIF：适合短交互，不适合完整叙事，也无法承载语音解释。
- 堆叠徽章与完整功能表：视觉上接近部分高星项目，但会增加维护面并稀释核心工作流。
- 使用既有个人配置截图：制作更快，却可能泄露设置且混入与 `main` 不一致的插件。

## Consequences

README 与英文侧保持结构镜像，并继续受 350 词预算约束。`docs/assets/` 需要随界面演进更新首页图与视频；大版本功能变化时应重录，而不是让媒体成为过时事实源。视频制作中间件留在本地报告目录，仓库只保留展示所需成品。
