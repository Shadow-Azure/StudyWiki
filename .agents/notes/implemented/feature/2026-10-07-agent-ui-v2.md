# Agent Note: Agent 面板交互 v2：回合过程折叠与审批接管输入区

Status: implemented

[English](2026-10-07-agent-ui-v2.en.md) | 中文

## Problem

m2-03 交付的基础 agent 面板把每个工具调用平铺在 transcript，头部堆叠会话下拉、审批切换、默认模式下拉与模型下拉四类控件；审批以大卡片插入对话流。用 MiniMax 真实回合实测确认：过程噪声淹没助手结论、待审批视觉弱、决策完成后仍占大块空间、“当前模式”与“新会话默认模式”两个相似控件并列难以区分。

## Decision

以 dsh Web UI（`ui-chat` 回合折叠、`ui-approval` 审批接管 composer、`ui-model-selection` composer 模型座位）为蓝本，融合 codex TUI（`approval_overlay.rs`：动作化选项 + Esc 恒为取消）与 Claude Code（`PermissionPrompt/PermissionDialog`：输入区接管 + 上方详情块）的审批模式，重排 `app-agent` 单插件内 UI（不动 `agent-core` 服务面）：

1. **回合过程组**：`tool-start/tool-end` 写入当前组的折叠体，运行中摘要行显示“正在执行 <tool>”；`turn-end` 自动 settle 为“已完成 N 个动作 · 耗时”，焦点在组内时不收起；`aborted/error` 同样收尾防悬挂。历史渲染以 `assistant.toolCalls` 为数据源（`SessionLine` 无独立工具结果行，结果内容本就不落账），占位文案“历史记录未含结果内容”。
2. **审批接管 composer**：审批到达不再向 transcript 插卡，composer 进入三态（normal → approval → decided）。approval 态红色描边，输入区显示请求摘要，底部行“查看详情 ▾ / 模型 pill / 批准 ⌘⏎ / 拒绝 Esc”；详情浮层锚定 composer 上方（路径、变更字符数、diff、授权范围说明）。决策写入 `renderDecisionLine` 一行记录，composer 经 decided 短态恢复 normal 并还原草稿；多审批排队，逐个呈现。Esc 语义分层：浮层开 → 只关浮层；否则 → 拒绝当前审批。
3. **header 单行化**：标题 + 状态点 + 新建/历史/更多；历史浮层可搜索（`paintSessionOptions` 按 title 过滤），模型选择移入 composer pill 菜单（按 endpoint 分组），新会话默认模式移入“更多”菜单。错误改为可关闭 toast（5s 自动消失）；composer 下缘新增状态行，回合运行态由事件驱动（`turnRunning`）而非依赖 `session.running` 快照。

## Alternatives considered

- **保留 transcript 审批大卡**（m2-03 形态）：决策完成后仍占大块高度，且审批与“当前正在看的内容”争夺注意力——被 composer 接管替代。
- **头部保留模型下拉**：与历史下拉并排造成两个语义相近的 select；模型切换发生在“准备发送”时，归 composer 座位更符合 dsh/claude 一致心智。
- **历史工具行虚拟 `type: "tool"`**：`SessionLine` 无该类型；伪造测试行会掩盖“结果不落账”的真实契约，改为 assistant.toolCalls 渲染。

## Scope

`src/plugins/app-agent/{index,render}.ts`、`src/styles.css`、`tests/app-agent*.ts`、`tests/ui-preview.test.ts`。`agent-core` 服务接口、审批协议与 JSONL 持久化未动。交互定稿与高保真预览见 `plans/2026-10-07-agent-ui-dsh.md` 与 `plans/agent-ui-preview-v2.html`（issue #52）。

## Consequences

- 优点：回合过程默认只保留结论与耗时；审批在 composer 内完成且详情按需展开；头部控件归位后信息层级更清晰。
- 代价：`app-agent` DOM 状态机与事件接线更复杂，历史会话中的动作结果只能展示持久化契约允许的占位说明。
- 欠账：审批详情的规则说明仍来自当前请求字段；后续若 guardian 提供更细授权范围，需要扩展协议与浮层。
